# Azurel

Android emulator experiment based on Torzu `6ead429`.

- `main`: original Torzu emulation source, Azurel packaging and Android CI.
- `compat/totk-1.4.x`: selective audio/HID/service backport for testing TOTK 1.4.2 and 1.4.3.
- [Compatibility, credits and test status](docs/azurel/COMPATIBILITY.md).
- [Upstream README](README.upstream.md).

Build artifacts: **Actions → Azurel Android**. Game compatibility requires device testing.
